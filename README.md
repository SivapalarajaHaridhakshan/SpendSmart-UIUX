\# SpendSmart — UI/UX Design Project



\## Project Overview

SpendSmart is a personal finance management app concept designed for university students in Sri Lanka.



\## Project Objective

Help university students manage their daily expenses, monthly budgets, income and savings goals.



\## Project Type

UI/UX Design



\## Design Tool

Figma



\## Target Users

University students in Sri Lanka.



\## Main Features

\- Personal finance dashboard

\- Income and expense tracking

\- Monthly budget management

\- Savings goals

\- Spending reports and analytics

\- User profile and settings



\## Project Development

This project will follow the UI/UX design process:

1\. User research

2\. Competitor analysis

3\. User personas

4\. User flows

5\. Wireframes

6\. UI design

7\. Interactive prototyping

8\. Usability testing
